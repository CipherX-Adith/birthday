# Photos Directory

Place your custom images for the birthday wishing webpage in this folder. 

## Recommended Files:
1. **`birthday-person.jpg`**: This will be used as the main portrait photo in the golden circle frame on the home screen.
2. **Gallery Images**: Add your memorable photos here and name them:
   - `gallery1.jpg`
   - `gallery2.jpg`
   - `gallery3.jpg`
   - `gallery4.jpg`
   - `gallery5.jpg`
   - `gallery6.jpg`

If any of these images are missing, the webpage will gracefully fall back to displaying the elegant gold outline botanical vector placeholder from `assets/birthday-person-placeholder.svg`.
